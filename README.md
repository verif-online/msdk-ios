# VerifSDK

VerifSDK позволяет встроить проверку документов и селфи в iOS-приложение.

## Требования

- iOS 16.0 или новее.
- Xcode и Swift Package Manager.
- Доступ к Verif API и сервер приложения, который выдаёт токен сессии для запуска проверки.
- Интернет и разрешение на использование камеры.

## Подключение

1. В Xcode выберите **File → Add Package Dependencies…**.
2. Укажите `https://github.com/verif-online/msdk-ios`.
3. Выберите версию `0.1.1` и добавьте продукт **VerifSDK** в приложение.

```swift
import VerifSDK
```

## Разрешение камеры

Добавьте в `Info.plist` приложения:

```xml
<key>NSCameraUsageDescription</key>
<string>Камера нужна для съёмки документа и селфи.</string>
```

## Запуск проверки

1. Получите с вашего сервера `token` и `expiresAt`.
2. Создайте `SdkSessionCredentials`, передав токен и срок действия как `Date`.
3. Передайте сессию в `VerifSessionConfiguration` и откройте SDK через `Verif.start`.
4. Обработайте результат в `onFlowFinished`, а ошибку запуска или выполнения — в `onError`.

Сервер приложения сам вызывает `/sdk/init`. Ключи и секрет для подписи в приложение не передаются.
Для каждой новой попытки получайте новую сессию. Для обновления токена можно передать `refreshSession`.
