# VerifSDK

VerifSDK позволяет встроить проверку документов и селфи в iOS-приложение.

## Требования

- iOS 16.0 или новее.
- Xcode и Swift Package Manager.
- Доступ к Verif API и сервер приложения, который выдаёт подписанные данные для запуска проверки.
- Интернет и разрешение на использование камеры.

## Подключение

1. В Xcode выберите **File → Add Package Dependencies…**.
2. Укажите `https://github.com/verif-online/msdk-ios`.
3. Выберите версию `0.1.0` и добавьте продукт **VerifSDK** в приложение.

```swift
import VerifSDK
```

Версия `0.1.0` готовится к публикации; установка станет доступна после её выпуска.

## Разрешение камеры

Добавьте в `Info.plist` приложения:

```xml
<key>NSCameraUsageDescription</key>
<string>Камера нужна для съёмки документа и селфи.</string>
```

## Запуск проверки

1. Получите с вашего сервера подписанное тело запроса и значения `apiKey`, `timestamp`, `signature`.
2. Создайте `SdkInitCredentials`, передав тело без изменений через `signedBody`.
3. Передайте credentials в `VerifConfiguration` и откройте SDK через `Verif.start`.
4. Обработайте результат в `onFlowFinished`, а ошибку запуска или выполнения — в `onError`.

Секрет для подписи храните только на сервере. Для каждой новой попытки получайте новые данные запуска.
