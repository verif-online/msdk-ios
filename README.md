# VerifSDK для iOS

VerifSDK добавляет в приложение проверку документов и селфи. Приложение получает
сессию от своего сервера и открывает экран SDK. Какие шаги пройти, определяет
настроенный в Verif процесс.

## Требования

- iOS 16.0 или новее.
- Минимальная поддерживаемая версия Xcode: **27.3**.
- Сервер приложения, который выдаёт сессию проверки в Verif.
- Интернет и разрешение камеры в приложении.

## Подключение

1. В Xcode откройте **File → Add Package Dependencies…**.
2. Введите `https://github.com/verif-online/msdk-ios`.
3. Выберите **Exact Version → 0.2.0** и добавьте продукт `VerifSDK`.
4. Добавьте `NSCameraUsageDescription` в `Info.plist` приложения.

В коде достаточно `import VerifSDK`. SwiftPM подключает один XCFramework и
автоматически добавляет отдельный bundle с ресурсами.

## Запуск проверки

Сервер приложения вызывает `/sdk/init` и передаёт приложению `token` и `expiresAt`.
Передайте их в `SdkSessionCredentials` и `VerifSessionConfiguration`, затем вызовите
`Verif.start`. Серверный секрет в приложение не передаётся.

Примеры для SwiftUI и UIKit, обработка результатов, продление сессии, тема и тексты:
[руководство по интеграции](Docs/Usage.md).

Если проект уже использовал первоначальный `0.2.0`, обновите кэш SwiftPM и заново
разрешите зависимость. Проверку checksum отключать не нужно.
