# VerifSDK для iOS

VerifSDK проводит пользователя через проверку документов, заполнение данных и селфи.
Подключите пакет, получите сессию от своего сервера и откройте экран SDK.

Версия **0.2.0** поставляется одним `VerifSDK.xcframework` и отдельным bundle
ресурсов. SwiftPM подключает их автоматически; в приложении нужен только
`import VerifSDK`.

## Требования

- iOS 16.0 или новее.
- Приложение на SwiftUI или UIKit.
- Для этой поставки используется Xcode 27.3 Beta. Совместимость бинарного пакета
  с более ранними Xcode отдельно не подтверждена.
- Ваш сервер, который выдаёт сессию проверки, и доступ к интернету.
- Разрешение камеры и реальный iPhone для проверки съёмки.

Tuist, Docker и сборка исходников SDK интегратору не нужны.

## Подключение

1. В Xcode выберите **File → Add Package Dependencies…**.
2. Укажите `https://github.com/verif-online/msdk-ios`.
3. Выберите **Exact Version → 0.2.0**.
4. Добавьте продукт **VerifSDK** в target приложения.
5. Используйте `import VerifSDK`.

Ресурсы доставляются пакетом автоматически; отдельно копировать bundle при
SwiftPM-подключении не нужно.

## Разрешение камеры

Добавьте в `Info.plist` приложения:

```xml
<key>NSCameraUsageDescription</key>
<string>Камера нужна для съёмки документа и селфи при проверке личности.</string>
```

## Запуск

1. Получите с вашего сервера `token` и `expiresAt`.
2. Преобразуйте срок действия в `Date` и создайте
   `try SdkSessionCredentials(token:expiresAt:)`.
3. Передайте сессию в `VerifSessionConfiguration`; для dev задайте
   `baseURL: URL(string: "https://api.dev.verif-online.ru")!`.
4. Откройте проверку через `Verif.start` и подключите **оба** обработчика:
   `onFlowFinished` для результата и `onError` для технической ошибки.
5. Закройте экран SDK из обработчика. Перед новой попыткой получите новую сессию.

Ваш сервер сам вызывает `/sdk/init`. API-ключи, секреты и подпись в приложение
не передаются. Без явного `baseURL` SDK использует production:
`https://api.verif-online.ru`. Не смешивайте сессию dev с production-адресом.

Готовые примеры SwiftUI и UIKit, обработка результата, обновление сессии,
замены строк и адаптивные цвета: **[руководство интегратора](Docs/Usage.md)**.

## Обновление с 0.1.x

Удалите прямой `import VerifSDKDesignSystem` и используйте `import VerifSDK`.
Имена вида `VerifSDKDesignSystem.VerifTheme` замените на `VerifTheme`.
При ручной интеграции удалите старый `VerifSDKDesignSystem.xcframework` из проекта:
он больше не нужен. Готовые бинарные обёртки над SDK нужно пересобрать с 0.2.0.
Приложение тоже необходимо пересобрать; старую и встроенную дизайн-систему
нельзя подключать одновременно.
